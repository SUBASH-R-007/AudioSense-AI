Anatomy animations live here.

Filenames are derived from the selection key in
`backend/app/clinical/anatomy_video.py`, so `perforation.mp4` must be exactly
that. See ANATOMY_VIDEOS.md in the repository root for the Veo prompts, the
encoding settings, and the full file list.

Clips that are not here yet degrade to the written explanation — the panel
probes each file before it renders a player, so you can add them one at a time.
